# 交付与提车指南

## 交付周期

锁单后预计交付时间参考（2026年7月）：

| 车型 | 常规配置 | 特殊颜色/选装 |
|------|---------|-------------|
| G6 | 2-4周 | 4-6周 |
| G9 | 3-5周 | 5-7周 |
| P7+ | 2-4周 | 4-5周 |
| MONA M03 | 1-3周 | 3-4周 |
| X9 | 4-6周 | 6-8周 |

以上为参考周期，实际交付时间以锁单时系统显示的预计交付日为准。

## 交付流程

完整的提车流程如下：

1. 车辆到店后，交付专员电话通知用户
2. 用户预约提车时间
3. 到店后PDI检测（用户可全程参与）
4. 支付尾款及办理保险
5. 办理临时牌照或正式上牌
6. 车辆功能讲解（约40分钟）
7. 智驾功能激活指导
8. 提车离店

全程约需1.5-2小时。

## 现车与在途车

部分车型有现车或在途车，可大幅缩短等待时间：

- 现车：支付尾款后1-3天可提车
- 在途车（已生产在运输中）：到店后即可提车
- 建议咨询当地体验中心是否有现车资源

## PDI检测说明

每台新车到店后均需经过PDI（Pre-Delivery Inspection）检测，包括：

- 外观漆面检查
- 内饰功能测试
- 三电系统检测
- 车机系统激活及OTA升级
- 辅助驾驶功能校准

PDI检测由小鹏授权技师完成，用户可在提车时查看检测报告。

## 上牌服务

小鹏体验中心提供一站式上牌服务：

- 临牌：提车当天即可办理（有效期15天，可续办一次）
- 正式牌照：提车后7-15个工作日内办结
- 所需材料：身份证、购车发票、交强险保单、合格证
- 限牌城市需先取得购车指标

## 提车注意事项

提车时建议核对以下项目：

- 车辆外观有无划痕、色差
- 内饰有无污损、破损
- 仪表盘里程数（正常应在50km以内）
- 车辆VIN码与文件是否一致
- 随车工具及附件是否齐全（充电线、脚垫、三脚架等）
- 车机系统功能是否正常
