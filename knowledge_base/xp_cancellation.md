# 退订与退款说明

## 订金退款规则

订金5,000元在以下情况下可全额退还：

- 锁单前：随时可申请退订，订金全额原路返还，到账时间1-7个工作日
- 锁单后：如因个人原因取消订单，订金退还将按当期政策执行
- 车辆交付延迟超过承诺时间30天以上：用户可选择全额退订

退款路径与原支付方式一致。

## 锁单前退订流程

锁单前取消订单操作流程：

1. 登录小鹏APP → 我的订单
2. 选择需要取消的订单
3. 点击"取消订单"并确认
4. 订金将在1-7个工作日内原路退还

如遇到退款问题可联系在线客服或致电400客服热线。

## 锁单后退订说明

锁单后车辆已进入排产状态，取消规则如下：

- 排产中取消：订金部分退还（以当期政策为准）
- 已生产未发运：已产生的配置成本将从订金中扣除
- 已发运在途：全额订金不可退
- 因车辆质量问题或交付延期导致的取消：订金全额退还

建议锁单前确认好配置和购车意向。

## 购车合同取消

已签订购车合同后取消，需按合同约定执行：

- 全款用户：扣除已产生的费用后退还余额
- 分期用户：需同步联系金融机构取消贷款合同
- 置换用户：需同步取消旧车置换手续

所有取消操作均需到店办理，建议提前联系交付专员。

## 退款到账时间

| 支付方式 | 到账时间 |
|---------|---------|
| 支付宝 | 1-3个工作日 |
| 微信支付 | 1-3个工作日 |
| 银行卡转账 | 3-7个工作日 |
| POS刷卡 | 3-7个工作日 |

如超过预计时间未到账，请联系客服查询退款进度。
