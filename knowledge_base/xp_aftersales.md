# 小鹏汽车售后服务规则

## 一、保养政策

### 保养周期

| 保养类型 | 周期 | 费用 |
|---------|------|------|
| 首保 | 6个月或5,000公里（先到为准） | 免费 |
| 常规保养 | 每12个月或20,000公里（先到为准） | 约580-880元/次 |

### 常规保养项目
- 三电系统状态检测（电池健康度SOH、电机运行状态、电控系统诊断）
- 制动系统检查（刹车片厚度、制动液状态）
- 底盘螺栓力矩检查
- 空调滤芯清洁/更换
- 轮胎磨损及胎压检查
- 灯光系统检查
- 雨刮片检查
- 整车控制器（VCU）软件版本检查与升级

### 大保养（每24个月或40,000公里）
在常规保养基础上增加：
- 制动液更换
- 冷却液（电池冷却系统+电机冷却系统）液位及状态检查
- 12V蓄电池状态检测
- 高压线束绝缘检查

## 四、保养与质保的前提条件

1. 车辆需在小鹏汽车授权服务中心进行定期保养，并保留完整的保养记录
2. 使用小鹏认可的配件和油液（制动液、冷却液等）
3. 按《用户手册》和《保修保养手册》规定的周期和要求进行维护
4. 不得擅自改装车辆关键系统（三电系统、底盘、刹车系统、电气系统）
5. 车辆用于非营运用途（营运车辆质保条款另行规定）

---

## 五、不在保修范围的情况

1. 未按保养手册要求进行定期保养
2. 使用非官方认证的配件或油液导致的故障
3. 自行或非授权第三方对车辆进行改装、维修
4. 意外事故、碰撞、自然灾害（洪水、火灾、地震等）导致的损坏
5. 正常磨损（如刹车片磨损、轮胎磨损等）
6. 车辆用于赛车、越野比赛等极端用途
7. 车主故意损坏或严重疏忽导致的故障
8. 里程表被人为改动导致无法确认真实里程

## 六、道路救援服务

### 服务对象与范围
在整车质保期内，因产品质量问题导致车辆无法行驶的，小鹏汽车在中华人民共和国境内（不含港澳台）提供免费道路救援。

### 免费救援服务
- 远程诊断：通过车载T-BOX远程诊断故障
- 现场诊断：安排移动服务车及技师赶赴现场
- 拖车救援：将车辆拖送至最近的小鹏授权服务中心或超充站

### 非免费项目（由车主承担费用）
- 困境救援（需大型吊车等专业设备）：如车辆陷入沟渠、泥地等
- 特殊路段救援（高速/高架/隧道等）：需联系交警安排第三方拖车
- 因交通事故、轮胎扎钉、爆胎、电量耗尽等非质量问题导致的救援

### 救援联系方式
- 24小时服务热线：400-783-6688
- 小鹏APP → 一键救援
- 车载大屏 → 道路救援按钮

## 八、退换车政策

### 三包退换条件

以下情况适用退换车：
1. 购车60日内或行驶3,000公里内（先到为准），制动系统失效、转向系统失效、车身开裂、燃油泄漏（增程车型）、动力蓄电池起火
2. 因严重安全性能故障累计修理2次仍未排除
3. 三电系统（动力电池、驱动电机、电机控制器）同一主要零部件更换2次仍不能正常使用
4. 因产品质量问题累计修理超过35日
5. 因同一产品质量问题累计修理超过5次

### 三包退换计算
符合退车条件的，消费者需支付合理的使用补偿费：
补偿费 = 车价 × (行驶里程/1000) × 0.5%

## 十、维修流程

1. **预约**：小鹏APP或致电服务中心预约
2. **到店**：按预约时间到店
3. **接车检查**：服务顾问与客户确认车辆状况和维修项目
4. **维修施工**：技师按照诊断结果进行维修
5. **质检**：维修完成后进行质量检验
6. **交车**：客户验收，确认维修效果
7. **回访**：维修后48小时内客服回访满意度

### 维修时长参考

| 维修项目 | 预计时长 |
|---------|---------|
| 常规保养 | 1-1.5小时 |
| 软件升级 | 30-60分钟 |
| 空调滤芯更换 | 20分钟 |
| 制动液更换 | 1小时 |
| 钣金喷漆 | 2-5个工作日（视面积和工艺） |
